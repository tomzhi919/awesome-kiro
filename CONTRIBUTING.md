# Contributing to awesome-kiro

Thanks for your interest in contributing! 🎉

## Guidelines

### Adding a project

1. Make sure the project is related to Kiro IDE or Kiro CLI
2. The project should have a clear README and be actively maintained
3. Add it to the appropriate section in alphabetical order
4. Use this format:

```markdown
- [owner/repo](https://github.com/owner/repo) — Short, clear description ending with a period.
```

### Quality standards

- **Active**: At least one commit in the last 6 months
- **Documented**: Has a README that explains what it does and how to use it
- **Useful**: Solves a real problem for Kiro users
- **Working**: The code/tool should actually work

### What doesn't belong

- Abandoned projects (no updates in 6+ months)
- Duplicates of existing entries
- Self-promotion without substance
- Projects that only mention Kiro in passing but aren't actually useful for Kiro users

## Process

1. Fork this repository
2. Create a branch: `git checkout -b add/your-project`
3. Add your entry in the correct section
4. Commit: `git commit -m "Add owner/project-name"`
5. Push and open a Pull Request
6. In your PR description, briefly explain why it's awesome

## Updating existing entries

If a project has moved, been renamed, or the description is outdated, PRs to update are welcome.

## Removing entries

If a project is no longer maintained, broken, or has become irrelevant, open an issue or PR to remove it.
